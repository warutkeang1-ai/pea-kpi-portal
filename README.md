# PEA Chumphae (KPI Portal)
ศูนย์รวมลิงก์ระบบติดตาม KPI (รวมลิงก์เท่านั้น ไม่ดึงข้อมูลจากระบบปลายทาง)

## ติดตั้งและรัน
    npm install
    npm run dev        # เปิด http://localhost:5173
    npm run build      # ผลลัพธ์ในโฟลเดอร์ dist/
    npm run preview

## เพิ่ม/แก้ไข/ลบลิงก์
1. เปิดหน้าเว็บด้วย `/#admin` แล้วใช้ปุ่ม "เพิ่มลิงก์", "จัดลำดับ" (เลื่อน/ซ่อน/แก้ไข/ลบพร้อมยืนยัน), "แบนเนอร์" (ใส่ URL รูป) และปุ่มออกจากโหมดผู้ดูแล
2. URL ต้องเป็น http/https เท่านั้น เว้นว่างได้ (จะแสดง "ยังไม่ได้กำหนดลิงก์")
3. **สำหรับผู้ใช้ทุกคน**: กด "คัดลอก JSON" แล้ววางทับ `src/data/links.json` จากนั้น build/deploy ใหม่
   (ข้อมูลที่แก้ในหน้าเว็บเก็บใน LocalStorage ของเครื่องนั้นเท่านั้น ไม่ซิงก์)
4. ใส่โลโก้จริง: วางไฟล์โลโก้ชื่อ `logo.png` ในโฟลเดอร์ `public/` ระบบจะแสดงให้อัตโนมัติ

## Deploy
- **Netlify**: build command `npm run build`, publish directory `dist`
- **GitHub Pages**: push โค้ดขึ้น GitHub → build → publish โฟลเดอร์ `dist` (เช่น ด้วย `gh-pages` หรือ GitHub Actions) — `base: './'` ตั้งไว้แล้ว

## ข้อจำกัดก่อนใช้งานจริง
- `#admin` ไม่ใช่ระบบความปลอดภัย ใครรู้ก็เปิดได้ (แต่แก้ได้เฉพาะในเบราว์เซอร์ตนเอง)
- ไม่มีฐานข้อมูล/การยืนยันตัวตน: ต้องการแก้ร่วมกันหลายคนให้เปลี่ยน `src/storage.ts` ไปเรียก API + SSO
- ไม่ตรวจสถานะเว็บปลายทาง; URL ทุกรายการยังว่าง ต้องกรอกจริง
- ไม่มีโลโก้ทางการ ใช้ข้อความ PEA ชั่วคราว; รายการแผนกบริการลูกค้า/มิเตอร์เป็นข้อมูลตัวอย่าง
